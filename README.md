# YIDU-彭 · 摄影师个人作品网站

深色画廊风格的摄影师个人网站：首页展示昵称 **YIDU-彭**，以作品集为核心，关于（个人详细介绍）与简历（教育 / 技能 / 证书）为辅助。已部署到 GitHub Pages。

## 🌐 在线地址

**https://brm-yidu.github.io/resume/**

## 日常更新内容（推荐流程，全程无需写代码）

1. 双击 **start.bat**（或直接双击 `resume-tools\editor.html`）打开「网站管理器」——**不需要 Python，也不需要服务器**。
2. 在管理器点击「① 连接网站目录」，选择本 `resume` 文件夹。
3. 切到「📷 作品」页签：拖入作品图片、填写分类/标题/描述，可排序、删除、换图。
4. 切到「✏️ 网站信息」页签：可修改首屏 Hero（图片/名字/引言）、关于我（肖像/介绍/优势）、简历（技能/教育/证书）、联系与页脚。
5. 分别点击保存按钮——图片自动存入 `images/`，数据写入 `data/` 目录。
6. 双击 **sync.bat**，自动上传到 GitHub，约 1 分钟后网站更新完成。

> 提示：若双击 start.bat 没有反应，可先重启电脑，或直接双击 `resume-tools\editor.html`（效果完全一样）。

## ⚠️ 隐私说明（重要）

**作品管理器（editor.html）只存在你的电脑本地，不会上传到网站**，别人无法通过搜索或网址访问到它。

- 管理器位置：`项目文件夹/resume-tools/editor.html`（与网站仓库分离）。
- 仓库中的 `.gitignore` 已排除该文件，sync.bat 不会把它上传。
- 部署在 GitHub 上的只有：网站页面、作品数据与图片，均为你希望公开的内容。

## 目录结构

```
项目文件夹/
├── resume/              # 网站仓库（GitHub 公开内容）
│   ├── index.html        # 网站主页面
│   ├── sync.bat          # 一键同步上线（git 提交并推送）
│   ├── start.bat         # 一键启动本地预览 + 作品管理器
│   ├── .gitignore        # 排除本地工具文件
│   ├── data/works.json   # 作品数据（由编辑器生成，网站自动读取）
│   ├── images/           # 作品图片
│   └── README.md
└── resume-tools/         # 仅本地（不会上传）
    └── editor.html       # 作品管理器（你的更新工具）
```

## 深浅模式

- 网站右上角有深浅模式切换按钮（☀/☾），选择会记住在浏览器里。
- 首次访问自动跟随系统设置。

## 修改个人信息（姓名 / 联系方式 / 简历）

- 推荐方式：用「网站管理器」的「✏️ 网站信息」页签修改，保存后运行 sync.bat 即可。
- 或直接编辑 `index.html` 中的默认数据、或 `data/site.js`（网站会自动读取）。
- 首页展示昵称 **YIDU-彭**；「彭基林」出现在关于区与简历副标题中；`<title>` 与 meta 描述同时保留"彭基林"便于搜索引擎收录。
- 联系方式（邮箱 / 电话）：在管理器「联系与页脚」区块修改。

## start.bat 打不开的排查

- 新版 start.bat 不依赖 Python，直接打开管理器；若仍未弹出，请直接双击 `resume-tools\editor.html`（效果一样）。
- 若曾多次运行旧版 start.bat，可能有残留的 python 进程占着端口：在任务管理器结束所有 python.exe 进程，或重启电脑即可。

## 网站数据说明

- 网站会自动加载 `data/works.json` 中的作品；文件不存在时显示内置示例作品（不影响浏览）。
- 作品图片缺失时自动显示同风格艺术占位图，不会破图。
- 分类筛选：全部 / 风景 / 人像 / 纪实 / 视频 / AI设计，点击作品可放大查看。

## 技术说明

- 单文件 HTML + 原生 CSS/JS，零依赖、零构建。
- 字体优先加载 Google Fonts，国内网络不可用时自动回退系统字体。
- 响应式：桌面端固定导航，移动端全屏抽屉菜单；支持打印样式。
- 旧版简历风页面保留为 `index-resume-v1.html`，可随时回退。
