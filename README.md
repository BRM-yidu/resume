# 彭基林 · 在线个人简历页面

简约大气的在线简历 / 作品集单页。深蓝色侧边栏 + 浅蓝色分栏，上下内容布局，桌面端与移动端均适配。可直接分享给面试官或合作伙伴（本地双击打开、上传到任意静态托管均可）。

## 目录结构

```
resume/
├── index.html      # 页面本体（所有样式与逻辑内嵌，单文件）
└── images/         # 作品图片目录（当前为空，页面自动显示精美占位图）
```

## 快速开始

直接双击 `index.html` 即可在浏览器打开。图片缺失时，页面会自动展示与作品主题匹配的 SVG 艺术占位图，不会出现破图。

## 替换为你的真实作品（约 5 分钟）

1. 将作品图片放入 `images/` 目录（建议 JPG，宽边 ≥ 1600px）。
2. 打开 `index.html`，搜索并修改 `WORKS` 数据（文件上部 `<script>` 内）：
   - 摄影作品：`photo` 数组（`cat` 字段为 `风景` / `人像` / `纪实`，决定子分类归属）
   - 视频剪辑：`video` 数组（视频作品可放封面图，卡片上有播放标识）
   - AI 设计：`ai` 数组
   - 每个作品只需改三处：`img`（图片文件名）、`title`（标题）、`desc`（描述）；`sub` 是英文小标，可自行修改。
3. 删除占位图提示：找到页面中「当前展示为占位作品」那行文字，替换或删掉即可。
4. 刷新页面，完成。

> 建议文件名与 `img` 字段保持一致，例如 `images/photo-landscape-1.jpg`。

## 替换教育背景与证书

搜索 `教育背景与证书` 区域：

- 教育经历：修改 `timeline` 中的「院校名称」「专业」与描述文字。
- 证书资质：`cert` 卡片中「证书名称」「颁发机构 · 年份」替换为真实信息。
- 完成后删除文中的 `「」` 占位符标记。

## 修改个人信息

- 联系方式（邮箱 / 电话）已内置在侧边栏、基本信息卡与联系区，共三处，均使用真实信息。
- 姓名「彭基林」、职位「摄影师 · 剪辑师 · AI设计师」如需微调，直接搜索替换即可。
- 技能熟练度百分比在 `skill-bar` 的 `data-w` 属性中修改。

## 部署上线（让面试官通过网址访问）

任选一种，10 分钟内可上线：

1. **Vercel / Netlify**：注册账号 → 新建项目 → 拖入本文件夹 → 部署，得到免费 HTTPS 网址。
2. **GitHub Pages**：新建仓库上传本文件夹 → Settings → Pages → 选择分支 → 生成 `https://<用户名>.github.io/resume/` 网址。
3. **国内云 / OSS**：上传到任意静态托管（如腾讯云 COS、阿里云 OSS）并开启静态网站托管，国内访问速度最快。

部署时请将整个 `resume` 文件夹一起上传（`index.html` 需要同目录的 `images/`）。

## 技术说明

- 单文件 HTML + 原生 CSS/JS，零依赖、零构建，打开即用。
- 字体优先加载 Google Fonts（Noto Serif SC / Cormorant Garamond），国内网络无法访问时自动回退到系统字体，不影响显示。
- 响应式：≥880px 显示侧边栏布局；移动端自动切换为顶部导航 + 抽屉菜单。
- 无障碍：语义化标签、键盘可关闭的灯箱、`prefers-reduced-motion` 适配。
