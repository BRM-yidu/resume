# YIDU-彭 · 摄影师个人作品网站

深色画廊风格的摄影师个人网站：首页展示昵称 **YIDU-彭**，以作品集为核心，关于（个人详细介绍）与简历（教育 / 技能 / 证书）为辅助。已部署到 GitHub Pages。

## 🌐 在线地址

**https://brm-yidu.github.io/resume/**

## 日常更新作品（推荐流程，全程无需写代码）

1. 双击 **start.bat**（或直接双击 **editor.html**）打开「作品管理器」。
2. 点击「① 连接网站目录」，选择本 `resume` 文件夹。
3. 把作品图片拖进管理器，填写分类 / 标题 / 描述，可排序、可删除、可换图。
4. 点击「② 保存并生成 works.json」——图片自动存入 `images/`，数据写入 `data/works.json`。
5. 双击 **sync.bat**，自动上传到 GitHub，约 1 分钟后网站更新完成。

> 提示：管理器要求使用 Edge / Chrome 桌面版浏览器。若浏览器不支持目录写入，可用「导出 works.json」备用方式：图片手动放入 `images/`，导出的文件放入 `data/`，再运行 sync.bat。

## 目录结构

```
resume/
├── index.html        # 网站主页面
├── editor.html       # 本地作品管理器（你的更新工具）
├── sync.bat          # 一键同步上线（git 提交并推送）
├── start.bat         # 一键启动本地预览
├── data/works.json   # 作品数据（由编辑器生成，网站自动读取）
├── images/           # 作品图片
└── README.md
```

## 网站数据说明

- 网站会自动加载 `data/works.json` 中的作品；文件不存在时显示内置示例作品（不影响浏览）。
- 作品图片缺失时自动显示同风格艺术占位图，不会破图。
- 分类筛选：全部 / 风景 / 人像 / 纪实 / 视频 / AI设计，点击作品可放大查看。

## 技术说明

- 单文件 HTML + 原生 CSS/JS，零依赖、零构建。
- 字体优先加载 Google Fonts，国内网络不可用时自动回退系统字体。
- 响应式：桌面端固定导航，移动端全屏抽屉菜单；支持打印样式。
- 旧版简历风页面保留为 `index-resume-v1.html`，可随时回退。
